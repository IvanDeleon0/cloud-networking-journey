# 🔒 Core Security Concepts

## Overview

This AWS Cloud Quest activity focuses on implementing security best practices using AWS Identity and Access Management (IAM). The lab demonstrates how to control access to AWS resources through users, groups, and policies while following the principle of least privilege.

## Objective

Implement IAM groups with least-privilege permissions to manage user access to AWS resources securely.

## AWS Services Used

- AWS Identity and Access Management (IAM)
- Amazon EC2
- Amazon RDS

## Key Concepts

### 👤 IAM Users

IAM users represent individual identities that can access AWS resources.

### 👥 IAM Groups

Groups simplify permission management by allowing multiple users to share the same set of permissions.

### 📜 IAM Policies

Policies define what actions users and groups can perform on AWS resources.

### 🔐 Principle of Least Privilege

Users should only receive the minimum permissions required to perform their tasks.

### 🛡️ Access Control

IAM helps protect AWS resources by controlling who can view, modify, or manage services.
